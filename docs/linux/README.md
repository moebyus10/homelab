# 📖 About

This repository documents my personal Linux Homelab built as part of my self-training in **System and Network Administration**.

The objective is to learn real-world Linux administration by completing practical labs covering server installation, networking, security, storage, automation, containerization, VPNs, and infrastructure management.

Each lab contains:

- 🎯 Objectives
- 🛠️ Commands executed
- 📋 Configuration files
- ✅ Validation steps
- 📚 Concepts learned
- 🧠 Skills practiced

Everything has been performed on a real Ubuntu virtual machine and documented step by step.
